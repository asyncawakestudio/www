# MailVet

**Author**: [Ayushman Chhabra](/#/blog/author/Ayushman%20Chhabra)

**Published**: 2026-08-01

**Modified**: 2026-08-01

MailVet identifies disposable emails. The service is exposed as a single API endpoint which gives a lot of flexilibity to businesses:

1. You can place it as a validation check on user signup before the request data hits the database.
1. You can run a cron job to scan recent signups 24-48 hours later to identify potential disposable emails, send a verification email. If response is `250 OK` wait for 24-48 hours, on no response delete the account. If response is `550 User unknown`, delete it anyway.
1. Plug it into your SMTP server, create a rule to send emails from all temporary emails to Junk.

There is a free tier which is great way to test it in staging environments. Give MailVet a shot at [https://verify.asyncawake.studio](https://verify.asyncawake.studio).
